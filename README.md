# What is this?

This is my 2d Pygame python game centered around the idea of the popular game called Cookie Clicker but designed around the current
situation in the world relating to AI boom and AI data centers.

Just like Cookie clicker you have to click a sprite to give you money! (Suprise). You can purchase upgrades like better GPUS!
