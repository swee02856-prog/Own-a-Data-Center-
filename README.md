# What are the games features?

Clicking the GPU Icon in the top right gives you money, there is a specified amount of money given to each gpu type when the player clicks on them.

So basically the better your GPU is the more money per click you earn.

Workers basically give you income, and income is added onto the current money you have right now but is given every second. Workers take the GPUs cash and multiplies it by how much they earn per second.

For Example the intern makes $5 per second and if you have the default starting GPU which makes $1 per click,
your income will still be $5 because 5 x 1  = 5.

# How do you win and How do you play?

To win you must save up enough money and buy the "Debt" upgrade.

**How do you get money?**

You get money from clicking on the GPU on the top right, clicking on it gives you some money, with that money you
can buy upgrades (get better gpus) or buy workers (which give you passive income). When you have enough money
you can beat the game by buying the "debt" upgrade which is $50,000 dollars!

Buying this "Debt" upgrade will put the win screen and officially tell you that you have saved the AI Bubble!

So basically in short, Click Top Right GPU = Money

Buy Workers = Passive Income

Passive Income = GPU Click x Worker Multiplier

To win = Buy "debt" upgrade
